# Lab 01 — Introduction to the Shell

**Script:** [`lab01.sh`](lab01.sh)

## What I did

This was the first lab, just getting comfortable with a Linux terminal before
writing actual scripts. I ran a few basic commands to print text, check who I
was logged in as, confirm my working directory, create a file, and list what
was in the directory.

- `echo` to print a message to the terminal
- `whoami` to show the currently logged-in user
- `pwd` to print the current working directory
- `touch` to create an empty file
- `ls` to list files and folders in the current directory

## Code

```bash
echo "Welcome to Shell Scripting"
whoami
pwd
touch test.txt
ls
```
